# MAHOROBA Care Ver.0.3

合同会社真秀場向け、架空データ専用の操作可能な試作品です。

## 起動方法
`index.html` を端末に保存し、ブラウザで開いてください。インストールや外部API、課金は不要です。

## 実装済み
- 9〜16時の業務予定
- 架空職員6名・業務10件
- 業務完了と担当変更
- 対応可能業務と予定負荷に基づく簡易自動割振
- 全員の負荷を緑・黄・赤で表示
- 高負荷時の応援候補を画面表示（通知なし）

## 注意
臨床利用禁止。実際の患者情報を入力しないでください。保存・認証・監査ログ・安全判定・勤務表連携は未実装です。操作内容は再読み込みで初期化されます。自動提案は医療上の判断や管理者の承認に代わりません。
